# 🎙️ Sales Heroes Arena

مختبر محاكاة صوتية عبر المتصفح يتدرّب فيه مندوب المبيعات على مكالمة بيع ضد عميل
ذكاء اصطناعي بشخصية خفية. العميل يستمع إليك ويردّ بشكل طبيعي داخل الشخصية، وبعد
انتهاء المكالمة تحصل على بطاقة تقييم كاملة مع نصائح تدريبية مبنية على أدائك.

> **نطاق الإصدار التجريبي (MVP).** واجهة بالعربية (RTL) بالكامل، سيناريو جاهز واحد
> (`عميل جديد – مكالمة اكتشاف`) + **منشئ عميل مخصص** (الاسم، مجال العمل، نقطة الألم،
> مستوى الصعوبة، وصف المنتج…). الكود منظم بحيث يمكن إضافة سيناريوهات ومزايا أخرى بسهولة.

---

## كيف يعمل

```
 المتصفح (لوحة التحكم)        ──►  خادم FastAPI (رموز + النتائج)
        │                                  ▲
        │ WebRTC                           │ يرسل نتيجة التقييم JSON
        ▼                                  │
 LiveKit (صوت فوري)           ◄──►  العميل الآلي بلغة Python (العميل الذكي)
```

- **`server.py`** – FastAPI: يعرض لوحة التحكم، يصدر رموز LiveKit مع **إرسال العميل
  الآلي تلقائيًا**، ويخزّن/يعيد نتائج التقييم. يدير أيضًا **السيناريوهات المخصصة**.
- **`agent.py`** – عامل العميل الآلي. يشغّل خط الصوت الفوري
  STT → LLM → TTS (Deepgram → Groq → Microsoft Edge neural voices) ويبقى داخل
  شخصية العميل، ثم يقيّم المندوب بعد انتهاء المكالمة.
- **`personas.py`** – الشخصيات الخفية، معايير التقييم، **وباني نصوص الشخصيات من ملف
  تعريف مخصص**. أضف سيناريوهات مستقبلية هنا.
- **`edge_tts_tts.py`** – مكون صوت العميل عبر Microsoft Edge (مجاني بلا مفتاح، صوت
  سعودي أصيل). يُختار الصوت تلقائيًا حسب السيناريو.
- **`static/`** – واجهة JavaScript عربية بدون خطوة بناء باستخدام `livekit-client`.

## المتطلبات

- **Python 3.11+**
- مشروع **LiveKit Cloud** مجاني: <https://cloud.livekit.io>
- مفتاح **Groq** مجاني (بدون بطاقة ائتمان): <https://console.groq.com/keys>
- مفتاح **Deepgram** (الخطة المجانية تشمل رصيدًا): <https://console.deepgram.com>

> اللغة الافتراضية عربية. للتبديل إلى الإنجليزية غيّر `STT_LANGUAGE=en` في `.env`
> واكتب نصوص الشخصيات باللغة المطلوبة في `personas.py`.

## الإعداد

```powershell
cd sdr-ai-training-lab

# 1. بيئة افتراضية وتثبيت المتطلبات
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt

# 2. الإعداد (لا تُرسِم مفاتيحك أبدًا في الكود)
Copy-Item .env.example .env
#    ثم عدّل .env واملأ:
#    LIVEKIT_URL / LIVEKIT_API_KEY / LIVEKIT_API_SECRET
#    GROQ_API_KEY
#    DEEPGRAM_API_KEY
```

## التشغيل

افتح **نافذتين** (مع تفعيل البيئة في كلتيهما):

```powershell
# النافذة 1 — تشغيل العميل الآلي
python agent.py dev

# النافذة 2 — تشغيل خادم الويب
python server.py
```

ثم افتح <http://localhost:8000> في Chrome أو Edge، انقر **🎙️ ابدأ التمرين**،
اسمح بالميكروفون، وتحدّث إلى عميلك.

## إنشاء عميل مخصص

في لوحة التحكم، قسم **«أنشئ عميلك الخاص»**: عرّف اسم العميل، مجال العمل، منصبه،
نقطة الألم، صاحب القرار، الحساسية للميزانية، نية الشراء، **مستوى الصعوبة**
(سهل/متوسط/صعب)، وأضف **وصف منتجك** اختياريًا — فيتقنه العميل ويطرح عنه أسئلة
واعتراضات واقعية. يُحفظ السيناريو على الخادم ويُعاد استخدامه.

## اختبار النجاح الأول

1. افتح اللوحة → تظهر بطاقة السيناريو.
2. انقر **ابدأ التمرين** → يظهر طلب إذن الميكروفون.
3. تسمع العميل يردّ على الهاتف. تحدّث بشكل طبيعي والعميل يردّ.
4. انقر **📞 إنهاء المكالمة** → تظهر بطاقة تقييم (الدرجات، نقاط القوة، مجالات
   التحسين، النصائح). انقر **🔄 إعادة السيناريو** للمحاولة مجددًا.

## متغيرات البيئة

انظر `.env.example` للقائمة الكاملة. كل الأسرار في `.env` فقط، أبدًا في الكود.
أهمها: `LIVEKIT_URL`/`LIVEKIT_API_KEY`/`LIVEKIT_API_SECRET` و`GROQ_API_KEY`
و`DEEPGRAM_API_KEY`، و`STT_LANGUAGE=ar` للعربية.

## تشغيل العميل الآلي على LiveKit Cloud (لاحقًا)

للنشر الاستضافي وجّه `EVALUATION_WEBHOOK_URL` و`SCENARIOS_BASE_URL` إلى خادمك
المنشور واستخدم `lk` لنشر العميل. الكود يدعم الإرسال بالاسم
(`AGENT_NAME`, الافتراضي `sdr-training-agent`) دون تغيير.

## هيكل المشروع

```
sdr-ai-training-lab/
├── agent.py              # العميل الآلي (العميل الذكي)
├── server.py             # خادم FastAPI (رموز، نتائج، ملفات، سيناريوهات مخصصة)
├── personas.py           # السيناريوهات، الشخصيات، معايير التقييم، باني الشخصيات
├── requirements.txt
├── .env.example
├── static/               # الواجهة (بدون خطوة بناء)
│   ├── index.html
│   ├── app.js
│   ├── styles.css
│   └── vendor/livekit-client.esm.mjs
├── data/results/         # ملفات نتائج التقييم (لكل غرفة)
└── data/scenarios/       # ملفات تعريف السيناريوهات المخصصة
```

## إضافة سيناريو لاحقًا

أضف إدخالًا جديدًا إلى `SCENARIOS` في `personas.py` (معرّف، بيانات عرض، `first_line`،
و`persona_prompt` يصف العميل الخفي). لوحة التحكم ونقطة الرموز والعميل الآلي
تلتقطه تلقائيًا. أو استخدم منشئ العميل المخصص من الواجهة دون أي كود.
